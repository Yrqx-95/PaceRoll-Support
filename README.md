# CleanSwipe Support

Static public help and privacy site for CleanSwipe / 清片. The app itself does not use this site as a backend and does not upload user photos or review decisions here.

This site is hosted through GitHub Pages from the `main` branch root. Public paths:

- `https://yrqx-95.github.io/CleanSwipe-Support/privacy/`
- `https://yrqx-95.github.io/CleanSwipe-Support/support/`

The English, Simplified Chinese, Traditional Chinese and Japanese sections live on the same pages. When app behavior or data practices change, update the policy's date and content, publish, and verify the public HTML before changing the App Store privacy answers.
